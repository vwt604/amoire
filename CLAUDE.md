## Stack

- **Hydrogen** 2026.1.1 — Shopify's headless commerce framework
- **React Router** 7 — file-based routing (migrated from Remix; never use `@remix-run/*` imports)
- **TypeScript** with path alias `~/*` → `app/*`
- **TailwindCSS** 4.x via Vite plugin
- **Oxygen** — Shopify's edge runtime (mini-oxygen for local dev)

## Commands

```bash
npm run dev          # start dev server with codegen watch
npm run build        # production build with codegen
npm run preview      # preview production build locally
npm run lint         # ESLint
npm run typecheck    # react-router typegen + tsc --noEmit
npm run codegen      # regenerate GraphQL and route types
```

No test runner is configured — ESLint and TypeScript are the quality gates.

## Architecture

### Server entry & context

`server.ts` is the Oxygen worker handler. `app/lib/context.ts` creates `HydrogenContext` per request, providing: Storefront API client, cookie-based session (`lib/session.ts`), cart, customer account, and i18n locale. This context flows into every route loader/action.

### Routing

File-based routes live in `app/routes/`. The `($locale)` prefix parameterizes all routes for i18n. `($locale).tsx` is the parent layout route. Route types are auto-generated by `react-router typegen` into `.react-router/types/` and imported as `./+types/[routename]`.

### Data fetching pattern

Routes use `loader()` for SSR data. The standard pattern separates "critical" data (awaited before render) from "deferred" data (returned as promises resolved in Suspense boundaries). Storefront queries use Hydrogen's caching strategies (e.g., `storefront.CacheLong()`).

### GraphQL

Queries and fragments are defined as tagged template literals in `app/lib/fragments.ts` and per-route files. `@graphql-codegen/cli` generates types into `storefrontapi.generated.d.ts`. Run `npm run codegen` after modifying queries.

### Styling

CSS files are imported with the `?url` suffix in `root.tsx` and injected via React Router's `<Links />`. TailwindCSS utilities are available globally.

### Cart & commerce

Cart mutations use `CartForm` from `@shopify/hydrogen` with action keys (`LinesAdd`, `LinesUpdate`, `LinesRemove`, `DiscountCodesUpdate`). Cart state is loaded in the root loader and passed through context.

## Key import rules

- Use `react-router` (not `@remix-run/*`) for all routing utilities
- Use `~/*` path alias for imports within `app/`
- CSS: import with `?url` suffix when used as a link href
